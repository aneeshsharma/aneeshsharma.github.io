This site just got rebuilt from the ground up — new design, new stack. It's
now an [Astro](https://astro.build) site: static output, content authored in
plain Markdown and YAML, deployed to GitHub Pages on every push.

Posts live at `src/content/blog/` as Markdown files. No CMS, no database —
just files in the repo, which felt like the right amount of tooling for a
site that gets updated a few times a year.
